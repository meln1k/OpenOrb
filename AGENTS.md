# OpenOrb agent instructions

Before starting work on any ticket:

1. Read `MASTER_PLAN.md` completely.
2. Read `MVP.md` completely. For MVP implementation, `MVP.md` overrides the broader scope in `MASTER_PLAN.md`.
3. Read `tickets/README.md` and the complete ticket being implemented.

Do not begin implementation until all four documents have been read. Follow their security boundaries, scope, dependencies, and acceptance criteria. Do not invent system design, architecture, protocols, persistence formats, or interfaces when they are not explicitly decided; ask the user instead.
