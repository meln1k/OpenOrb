# Sources and implementation references

Prefer installed-package documentation while implementing.

## Remix UI guide
- https://guides.remix.run/rendering-ui/

Key design ideas reflected by this skill:
- native controls can be styled/enhanced with mixins
- composed controls provide ready-to-use markup and behavior
- primitives exist when custom markup is required
- server rendering is the default; client JS is added only where interaction/browser APIs require it
- design tokens and styles belong to the application
